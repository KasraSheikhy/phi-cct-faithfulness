# Planned CSV contracts

These are schemas, not generated observations. Only the human-review header has been created initially. Do not treat an empty template as completed work.

- `frozen_sample.csv`: source_id, dataset_revision, split, source_row, premise, hypothesis, gold_semantic_label, sample_seed, sample_rank. Require 1000 distinct source IDs and record duplicate-text checks.
- `edit_proposals.csv`: source_id, edit_id, proposal_rank, family, method, role, original_text, edited_text, target, original_span_start, original_span_end, edited_span_start, edited_span_end, selection_status, rejection_reason, named_entity, entity_type, target_polarity, negation_flag, position_normalized, position_bin, idf, idf_bin, unseen_target. Offsets are zero-based Python character offsets, end-exclusive; document role-relative reference text. Insertions have an empty original span; deletions have an empty edited span. Validate edits by reconstructing the text.
- `edit_audit.csv`: follow `data/audit/edit_review_template.csv`. Preserve rejections and failures. Reviewer judgments remain blank until actual review.
- `raw_outputs.csv`: job_id, source_id, edit_id (baseline sentinel allowed), layout_id, model_id, model_revision, config_hash, prompt_hash, input_hash, raw_response, generation_status, parse_status, explanation, displayed_letter, semantic_label, input_tokens, generated_tokens, elapsed_seconds, stop_reason, error. Retain full prompt in a companion CSV keyed by prompt_hash.
- `paired_metrics.csv`: source_id, edit_id, family, layout_id, baseline_job_id, edited_job_id, gold_label_option_position, E_D, I_D, exact_mention, stem_mention, paper_rule_mention, validity_status, exclusion_reason, feature columns. A non-valid pair has missing E_D/I_D, never zero placeholders.
- `coverage.csv`: exactly one row per frozen source; expected/completed baseline and edited jobs, accepted/rejected proposals, valid edits per family, valid pairs per layout, generation/parse failures, insufficient_edits, completion_status. Also record totals in a run manifest, including preparation gaps before jobs exist.
- `summary.csv`: family, group, n_sources, n_pairs, valid_baseline_n, accuracy, full_coverage_correct_rate, n00, n01, n10, n11, phi, phi_ci_low, phi_ci_high, impact_rate, mention_rate, bootstrap_valid_draws, bootstrap_undefined_draws, status.
- `tests.csv`: family, variable, primary_or_secondary, null_hypothesis, formula, test_name, n_sources, n_pairs, n_groups, statistic, df, p_raw, p_bh, effect_description, status, nonestimable_reason. Store individual interaction effect estimates/CIs in a companion contrasts table.
- `plot_estimates.csv`: family, variable, level, n_sources, n_pairs, phi, ci_low, ci_high, impact_rate, mention_rate, valid_draws, undefined_draws, sparse, status.
- `qualitative_examples.csv`: example_id, source_id, edit_id, family, layout_id, baseline_job_id, edited_job_id, original/edited texts, target/spans, raw explanations, semantic predictions, E_D, I_D, case_type, interpretation, alternative_explanation. Include raw-row keys, including for failures.

CSV encoding is UTF-8, quoted fields preserve newlines, and missing values must remain distinguishable from zeros. Validate join cardinality and semantic option mapping before metric computation. Append-only checkpoints may use JSONL internally, but export the required CSV deliverables.
