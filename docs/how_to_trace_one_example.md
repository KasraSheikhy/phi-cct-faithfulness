# Trace one example from text to phi-CCT

Start with a `source_id` in `data/frozen/frozen_sample.csv`. Its premise, hypothesis, original gold semantic label and test-set revision are fixed before model outcomes. The gold label and the model's prediction are distinct fields.

1. Find an active `edit_id` for that source in `data/edits/selected_edits.csv`. Check the exact span against `target_span_reference`, reconstruct the edited text using the recorded original span and replacement, and consult the audit/quality exclusion files. A proposal's existence is not proof it is grammatical. The rejected item 20 is retained as an example of a dependency-parser failure.
2. Choose a `layout_id`. The three cyclic layouts map option letters to semantic labels. For example, A can mean entailment in one layout and neutral in another. For each paired comparison use the same layout before and after the edit.
3. Follow `baseline_job_id` and `edited_job_id` from `paired_metrics.csv` into `raw_outputs.csv`. Verify the prompts, raw responses, model revision, configuration hash and generation/parse status. Explanation comes before the final answer; Qwen's separate thinking mode is disabled. An unfinished/malformed response gives missing E_D/I_D, never zero.
4. Map the two answer letters through that layout. Set I_D=1 only if the **semantic model prediction** changes. This measures sensitivity, not correctness. A changed option letter across layouts is not by itself a semantic flip.
5. For insertion, search the **edited explanation** for the inserted target. For deletion, search the **matching baseline explanation** for the removed target. The deletion convention is an extension. The primary rule checks token boundaries or contiguous Snowball stems; a separate flag stores the paper's substring/stem rule. It can miss paraphrases or count irrelevant mentions, so inspect the actual wording.
6. Put a valid pair into one cell of the 2x2 table: n00 means E=0,I=0; n01 E=0,I=1; n10 E=1,I=0; n11 E=1,I=1. phi = (n00*n11 - n01*n10) / sqrt((n00+n01)*(n10+n11)*(n00+n10)*(n01+n11)). A constant margin makes phi undefined, not zero. Neither discordance direction automatically proves an individual explanation unfaithful.
7. When estimating uncertainty, resample the **source**, including all its edits and layouts together. Nine thousand responses are not nine thousand independent sources. Subgroup phi differences can reflect prevalence, vocabulary, template or quality differences; a small p-value does not establish a causal confounder.
